# The Food Models — Luxury Enterprise Web Experience
### A Specialized Subsidiary of City Scale Models Engineering S.A.E. (`city-scale.com`)

## 🚀 Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + Tailwind CSS Animate + Custom Glassmorphism & Mesh Gradients
- **Animations:** Framer Motion (staggered entrance reveals, 3D card tilt, interactive before/after sliders, interactive scale simulator, ripples)
- **Icons:** Lucide React
- **Celebration Effects:** Canvas Confetti
- **Bilingual Engine:** Instant English (LTR) / Arabic (RTL) switching with dynamic HTML `dir` attribute & font family synchronization (`Cairo` / `Readex Pro` for Arabic, `Cormorant Garamond` / `Plus Jakarta Sans` for English).
